# 02 — Architecture (Electron → SwiftUI map)

## 1. Original process model

- Main (`app/src/main-process/`): `BrowserWindow` lifecycle, single-instance lock, protocol/CLI/file-open handling, native menu build + `update-menu-state/execute-menu-item/show-contextual-menu`, open/save dialogs, shell/clipboard/trash, autoUpdater + GUID, window-state/zoom, proxy/cert, toast bridge, crash window, logging. `nodeIntegration:true, contextIsolation:false`.
- Renderer (`ui/index.tsx`, `ui/app.tsx`, `lib/stores/*`, `lib/git/*` via dugite, Dexie, localStorage, keytar): all `IAppState/IRepositoryState`, `Dispatcher/AppStore/GitStore`, git exec, IndexedDB, OAuth, update UI, drag-drop.
- Bridge (`lib/ipc-shared.ts`, `ui/main-process-proxy.ts`, `lib/ipc-renderer.ts`): simplex (`update-menu-state`, `menu-event`, `url/cli-action`, `window-state/zoom`, `quit/min/max/close`, `open-external`, `dialog-did-open`) + duplex (`get-path/arch`, `move-to-trash/show-item/clipboard/context-menu`, `is-window-focused/maximized/state/zoom`, `check-for-updates`, dialogs, guid, proxy, cert-trust, `is-in-application-folder/move-to-applications`).

SwiftUI: collapse to one process. Replace IPC with direct services:
`NSWindow/WindowGroup + AppDelegate openURLs/openFile` | `commands` for menu | `NSSavePanel/NSOpenPanel/NSWorkspace` | Sparkle for updates | Keychain (generic git/SSH only) | GRDB/SQLite or SwiftData (same tables as Dexie) | `UserDefaults` | `Sentry`-style crash POST | per-repo `actor GitStore` (`Process git` or libgit2) | `@MainActor ObservableObject AppState + actions`.

## 2. State shape (keep, minus deleted areas)

`IAppState` (`lib/app-state.ts`): `repositories: (Repository|CloningRepository)[]`, `recentRepositories: number[≤3]`, `localRepositoryStateLookup: Map<id, {aheadBehind, changedFilesCount}>`, `selectedState: Repository+IRepositoryState | CloningRepository+progress | MissingRepository`, `windowState/ZoomFactor/appIsFocused`, `sidebarWidth/commitSummaryWidth/stashedFilesWidth/branchDropdownWidth/worktreeDropdownWidth/pushPullButtonWidth: {value,min,max}`, `currentPopup/allPopups[≤50]/currentFoldout/currentBanner`, `currentDragElement`, `errorCount`, `emoji map`, `selectedTabSize/imageDiffType/hideWhitespaceInChanges/History/showSideBySideDiff/commitSpellcheckEnabled/showCommitLengthWarning`, confirm flags (repo-removal, discard-changes, discard-permanently, discard-stash, checkout-commit, force-push, undo-commit, commit-filtered, commit-override, worktree-removal), `uncommittedChangesStrategy`, `repositoryIndicatorsEnabled`, `underlineLinks(true)`, `showDiffCheckMarks(true)`, `optOutOfUsageTracking/useExternalCredentialHelper`, `currentOnboardingTutorialStep`, `updateState`, `showChangesFilter`.

`IRepositoryState` (per-repo, `RepositoryStateCache` keyed by `Repository.hash`): `commitSelection{shas,shasInDiff,isContiguous,changesetData,file,diff}`, `changesState{workingDirectory,commitMessage{summary,description,timestamp},showCoAuthoredBy,coAuthors,conflictState(merge|rebase|cherryPick|multiCommitOperation+manualResolutions),stashEntry,selection(workingDir{selectedFileIDs,diff}|stash{file,diff}),fileListFilter}`, `compareState{formState(History|CompareBranch{branch,mode:Ahead|Behind,aheadBehind}),mergeStatus,showBranchList,filterText,tip,commitSHAs,shasToHighlight,branches,recentBranches,defaultBranch}`, `branchesState{tip(Valid|Detached|Unborn|Unknown),defaultBranch,allBranches,recentBranches[5],pullWithRebase,forcePushBranches}`, `commitLookup/localCommitSHAs/localTags/remote/aheadBehind/tagsToPush`, `isPushPullFetchInProgress/isCommitting/checkoutProgress/pushPullFetchProgress/revertProgress/hookProgress/lastFetched/commitAuthor/commitToAmend/skipCommitHooks/signOffCommits/allowEmptyCommit`, `multiCommitOperationUndoState{undoSha,branchName}/multiCommitOperationState{step,operationDetail,progress,userHasResolvedConflicts,originalBranchTip,targetBranch}` (drop copilot subfields).

Swift mapping: `@MainActor final class AppStore: ObservableObject { @Published state: AppState }`, `RepositoryStateCache: [Int: RepositoryState]` (struct, copy-on-write `update*` helpers), `GitStoreCache: [Int: GitStore actor]`. Publish on main like `AppStore` (original emits on rAF, immediate if hidden). `PopupManager`: dedup except `Error`, cap 50.

## 3. Dispatcher → Swift actions

Original `ui/dispatcher/dispatcher.ts` (~200 methods, thin over `AppStore._*`). Port as `AppStore` methods grouped: lifecycle (`loadInitialState`, `selectRepository`, `refreshRepository`), repos (`addRepositories`, `removeRepository(moveToTrash:)`, `clone`, `setRepositoryFilterText`, `changeSection`), changes (`selectWorkingDirectoryFiles`, `changeFileIncluded/LineSelection/IncludeAll`, `setCommitMessage`, `commitIncludedChanges(ICommitContext)`, `discardChanges/FromSelection`, `start/stopAmending`, `undoCommit`, `resetToCommit`, `revertCommit`), branches/tags/worktrees (`create/rename/delete/checkout branch`, `create/delete tag`, `add/move/removeWorktree`), sync (`push/pull/fetch/publish/setRemoteURL/merge/rebase/continue/abort`), multi-commit (`launch/initialize/complete/end(Rebase|CherryPick|Squash|Reorder)`), UI (`showPopup/closePopup`, `showFoldout/closeFoldout`, `setBanner/clearBanner`, `setSidebarWidth/reset…`, `setAppMenuState/executeMenuItem`), prefs (`set*` per kept tab), external (`showInFinder`, `saveGitIgnore/appendIgnoreRule`), deep-link/CLI (`dispatchURLAction/dispatchCLIAction`), errors (`postError → presentError → .Error popup` via handler chain: upstream-exists, LFS, permissions, push-needs-pull, missing-repo, local-changes-overwritten, rebase, discard, secret-scan).

## 4. Persistence

- SQLite (replace Dexie `lib/databases/`): `repositories(++id,&path)`, `owners`, `protectedBranches` (keep; drop `pullRequests/issues/githubUsers` tables). 9-migration history — fresh install needs final schema only; provide import of old IDB if wanted (optional).
- `UserDefaults` (replace `lib/local-storage.ts`): widths, confirmations, `uncommittedChangesStrategy`, `tab-size/image-diff-type/hide-whitespace-*`, `commit-spellcheck-enabled`, `underline-links`, `diff-check-marks`, `show-changes-filter`, `last-selected-repository-id`, `recently-selected-repositories` (csv ≤3), `has-shown-welcome-flow`, `stats-opt-out`, zoom, tutorial flags. Drop `theme/dateFormat/timeFormat/numberFormat/high-signal-notifications-enabled` keys.
- Keychain (replace keytar `TokenStore`): generic git credentials + SSH passphrase/password only (no GH OAuth tokens). BYOK secrets: none.
- Files: logs (`~/Library/Logs/GitDesktop`), GUID file, window bounds via `NSWindowRestoration`.

## 5. Matching / grouping / onboarding / updates / crash / CLI / links

- Matching (`lib/repository-matching.ts`): `matchExistingRepository` (normalized path equality) keep; delete `matchGitHubRepository/urlMatchesRemote` GH parts. Grouping: none — only `recentRepositories[3]` (`updateRecentRepositories`: unshift prev id, filter missing, slice 3).
- Onboarding: `hasShownWelcomeFlow` + `TutorialStep{NotApplicable,PickEditor,CreateBranch,EditFile,MakeCommit,PushBranch,OpenPullRequest,AllDone,Paused,Announced}` via `tutorial-assessor.ts` (derive from `isTutorialRepo + branchCheckedOut + hasChangedFile + hasMultipleCommits + ahead==0`). Keep flow but replace PickEditor/OpenPullRequest steps: PickEditor → removed (no editors); OpenPullRequest → replaced by `PushBranch`-is-done (no PRs).
- Updates: main `autoUpdater` + renderer `UpdateStore{Checking|Available|NotAvailable|Ready|NotChecked, newReleases}` + banner/showcase (<15d + version>lastSeen) + `InstallingUpdate` popup blocks quit. Swift: Sparkle 2, same states.
- Crash: main `uncaughtException → POST {uptime,platform,arch,sha,version,guid} + CrashWindow 600×500`; renderer `onUncaughtException → sendErrorWithContext`. Swift: `NSException` handler + Swift `Error` boundary → `AppError` full-screen view (copy error, reopen) + opt-in report POST.
- CLI: `github [open][path]`, `github clone [-b] <url>`, `--help`; mac symlink `/usr/local/bin/github`, `CLIInstalled` popup; `second-instance` focus+forward. Swift: SwiftPM executable + symlink installer + `application(_:openFile:)` / URL scheme `x-gitdesktop-client://openrepo/<url>?branch&filepath` (drop `oauth?code&state`).
- Drag-drop app-level: `document.ondragover/ondrop → getPathForFile`; >1 → `addRepositories` + select first; 1 → toplevel resolve, match existing else `AddRepository{path}` popup. In-app commits: `DragType.Commit` only (drop GH fields).
