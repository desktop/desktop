# 03 — Design System (match original feel, system appearance only)

Source: `app/styles/_variables.scss`, `themes/_dark.scss`, `app/src/ui/lib/*`.

System: font `system-ui` (mono: `SFMono-Regular, Consolas, Menlo, monospace`); base `--font-size:12px` (sm 11, md 14, lg 28, xl 32, xxl 42, xs 9 — use sparingly); weight semibold 600 / light 300. Spacing `10px` base (double/triple/quad/quint, half/third). Radius `6px` (outline 3px). Borders `1px solid box-border`. Shadow `0 2px 7px rgba(71,83,95,.19)`. Easings: out-back `(0.175,.885,.32,1.275)`, in-back, out-quint. Dialog enter 250ms / exit 100ms, banner 500/400, undo-commit slide 500ms.

Toolbar (dark, keep exact): height `50px`, bg `#1f2428-ish gray-900`, text white, secondary `gray-300`, button hover `gray-800`, active (open foldout) inverts to white bg + dark text, progress fill `gray-800/700`, badge `gray-600` (active `gray-200`), tooltip `gray-800`. Titlebar: macOS 22px (26 large, 32 Tahoe), drag region, dbl-click minimize/maximize, light style only in welcome/no-repos.

Light values (dark = system dynamic equivalents — do NOT add a theme picker; use `Color(nsColor:)` / asset catalog `Any/Dark`):
text `gray-900`, secondary `gray-500`, bg white, box-alt `gray-100`, skeleton `gray-200`, border `gray-200`, border-contrast `darken(gray-400,5%)`, accent `blue`, selected (no focus) `#ebeef1`, selected+focus `blue` bg + white text, hover `gray-100`, focus ring `blue` + text-field shadow `rgba(blue,.25)`, placeholder `gray-500`.
Buttons: primary blue bg white text (hover lighten 5%), height `25px`, radius `6px`; secondary `gray-100` bg + contrast border (hover white); link-button `lighten(blue,5%)` hover `blue-600`. Text-field height `25px`.
Status colors: new `green-600`, deleted `red-600`, modified `darken(yellow-700,10%)`, renamed blue, conflicted `orange-800`. Diff: row 20px, line-number col 50px, padding-y 2px; add bg `darken(green-000,2%)`/border `green-300`/gutter `green-300`/inner `#acf2bd`; delete `red-000/red-200/red-100/#fdb8c0`; hunk `blue-000/blue-200/blue-100/gray-600`; hover `blue-300/400`; selected `blue-400/600` + white text; empty row `gray-000`; gutter `gray-200`. Syntax: variable `#6f42c1`, keyword `#d73a49`, atom `#005cc5`, string `#032f62`, comment `gray-500`, tag `#22863a`, header blue, quote `#1a7e31`.
Banner warning `yellow-100` bg + `darken(yellow-700,10%)` icon; error `red`/`red-100/200/800`; success `green-100/300/800`; info `blue-400`. Tooltip `gray-900` bg + `gray-100` text. Toast `rgba(gray-900,.6)` + `gray-000` text. Co-author tag `blue-000/blue-200`. Suggested-action primary `blue-000/blue-200`, icon `blue-400`. Rebase progress `green`. CI-ish merge status: pending `yellow-700`, error `red-500`, success `#1a7f37` (reuse for mergeability dot). z-index: tooltip 20 > popup 19 > overlay 18 > foldout 17 > nudge 16 > drag-overlay 15.
