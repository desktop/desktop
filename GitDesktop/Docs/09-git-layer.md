# 09 — Git Layer (commands, models, errors, progress)

Binary: dugite (`dugite@^3.2.3`) bundled git. Swift: bundle `git` (Xcode `git` credential helper note) and invoke via `Process` with identical args/env, or libgit2 where parity is proven. Default env every call: `TERM=dumb`, `GIT_TERMINAL_PROMPT=0`, `GIT_TRACE` (debug), `GIT_USER_AGENT=git/<v> (GitDesktop/<v>; mac arm64)`, `GIT_CONFIG_PARAMETERS='credential.helper=' 'credential.helper=desktop'`, trampoline token/port, SSH env. `maxBuffer`: string `kStringMaxLength`, buffer `Infinity`; diff caps 70MB / reasonable 4.375MB / 5000 chars/line; terminal output cap 256KB (log last 1024 chars).

## Commands (file → CLI; keep all)

- `core.ts/spawn.ts`: `git(args,path,name,opts{successExitCodes={0},expectedErrors,trackLFSProgress,isBackgroundTask,interceptHooks}) → {exitCode,stdout/stderr,result,gitError}`.
- Repo: `clone`: `git -c init.defaultBranch=<v> -c protocol.ext.allow=never -c protocol.ext.exe.allow=never clone --recursive [--progress] [-b] -- url path`; `initGitRepository`: `git -c init.defaultBranch=<v> init`; `rev-parse --is-bare-repository --show-cdup --git-dir` → bare|regular{top,gitDir}|missing|unsafe (dubious ownership); `rev-parse --symbolic-full-name <ref>@{upstream}`; `description` file read/write.
- Stage/commit: `add -- <p>` (conflicted); `update-index --add --remove --replace -z --stdin` (3-phase incl. forceRemove old-renames/deletes) + `applyPatchToIndex` (partial); `apply --cached --unidiff-zero --whitespace=nowarn -` / discard variant (no `--cached`); `commit -F - [--amend] [--no-verify] [--signoff] [--allow-empty]` (stdin msg, hooks `pre-commit,prepare-commit-msg,commit-msg,post-commit,post-rewrite,pre-auto-gc`) → `parseCommitSHA`; merge commit `commit --no-edit --cleanup=strip`; `reset --hard|--soft|<mixed> <ref> [-- paths]` (Win mixed `--stdin -z`); `unstageAll: reset -- .`; `rm --cached -r -f .`; `checkout-index -f -u -q --stdin -z`; `diff-index --cached --name-status --no-renames -z HEAD --` (128 unborn → NullTree `4b825dc…`).
- Status/diff: `status --untracked-files=all? --branch --porcelain=2 -z` (buffer) + `MERGE_HEAD/SQUASH_MSG/REBASE_HEAD/CHERRY_PICK_HEAD` checks + `diff --check` + `numstat` conflicts; `log <sha> [-w] -m -1 --first-parent --patch-with-raw --format= -z --no-color -- <p>`; merge-base diff `diff --merge-base`; range `diff <old^|NullTree> <latest>` (BadRevision→NullTree retry); `merge-base + diff --merge-base -C -M -z --raw --numstat`; working-dir `diff [-w] --no-ext-diff --patch-with-raw -z --no-color [HEAD -- p | --no-index -- /dev/null p (New, ok {0,1}) | -- p]` + CRLF warning parse; resolution diff via temp files `diff --no-index`; `diff --check` conflict markers `Map<path,count>`; `getFilesDiffText`: stage → `diff --staged` (10MB) → unstage.
- History/refs: `log --date=raw --format=<sha,short,summary,body,author,committer,parents,trailers,refs> --no-show-signature` (100KB caps); `log -C -M -m -1 --first-parent --raw --format=format: --numstat -z`; `rev-list --left-right --count <a..b|a...b>`; `rev-list <range> --reverse --oneline --no-abbrev-commit`; `for-each-ref --format…` (skip symrefs); `branch <n> [<start>] [--no-track]`, `branch --format`, `branch -m|-M` (+case retry), `branch -D`, `push <r> :<b>` + `update-ref -d refs/remotes/<r>/<b>` fallback, `branch --points-at`, `branch --merged`; `update-ref <ref> <new> <old> -m <reason>`, `update-ref -d`; `log -g … HEAD -n 2500` recent checkouts + `reflog --date=iso --after --grep-reflog=checkout`; `show <c>:<p>` (ok {0,1}), partial w/ maxBuffer; `merge-tree --write-tree --name-only --no-messages -z` → Clean|Conflicts|Invalid; `format-patch --unified=1 --minimal --stdout`; `interpret-trailers --parse/--trailer/--unfold`.
- Checkout/merge/rebase/cherry-pick/revert/stash/tags: `checkout [--progress] <name> [-b short if remote] --` + submodules (0-0.9/0.9-1 split); detached `checkout <sha>`; `checkout HEAD -- <paths>`; `checkout --ours|--theirs -- <p>`; `merge [--squash] [--no-verify] <b>` (hooks `pre-merge-commit,post-merge,commit-msg`) → Success|AlreadyUpToDate('Already up to date.\n')|Failed; `merge-base`; `merge --abort`; `rebase -- <base> <target>` (+`-c rebase.backend=merge` always); `rebase --abort/--skip/--continue`; interactive todo file; `cherry-pick <shas> --empty=keep -m 1`, `--continue` (`GIT_EDITOR=:`), `--abort`, sequencer reads; `revert [-m 1] <sha>`; stash `log -g --format… refs/stash --` (128→empty), `stash push -m marker` (exit1 w/o `error:` = ok, `No local changes`→false), `stash pop --quiet`, `stash drop`, `commit-tree -p … --no-gpg-sign + stash store`; `tag -a -m '' <n> <sha>`, `tag -d`, `show-ref --tags -d`, `push <r> <b> --follow-tags --dry-run --no-verify --porcelain` → `[new tag]`.
- Remotes/sync: `remote -v/add/remove(0,2,128 ok)/set-url/get-url`; `remote set-head -a` (0,1,128 ok); `fetch [--progress] --prune --recurse-submodules=on-demand <r>`; `fetch <r> <refspec>` (0,128 ok); `fetch . --show-forced-updates --no-write-fetch-head --stdin` (`GIT_REFLOG_ACTION=pull`, 0,1 ok); `pull [--ff if pull.ff unset] --recurse-submodules [--progress] [--no-verify] <r>` (hooks merge+rebase sets); `push <r> <local>[:<remote>] [tags] [--set-upstream] [--force-with-lease] [--no-verify] [--progress]` (hook `pre-push`).
- Submodules/LFS/worktrees/config/auth/hooks/ignore: `submodule update --init --recursive [-c protocol.file.allow=always]`, `submodule status --` (128→[]) `/^.([^ ]+) (.+) \((.+?)\)$/`, `submodule update --recursive --force -- <paths>`; `lfs install --skip-repo [--force]`, `lfs install [--force]`, `lfs track --json` (`NO_INSTALL_HOOKS=1`), `check-attr filter`; `worktree list --porcelain -z`, `worktree add [-b] <p> [<ish>]`, `remove [--force]`, `move`; `config -z [--global|--local] [--type]`, `--replace-all/--add/--unset-all`, `config --edit --global` w/ `printf`, `safe.directory` (+UNC prefix); `credential <fill|approve|reject>` w/ `key[]` parse; hooks `rev-parse --git-path hooks` + `config core.hooksPath`, 29 known hooks, exec check, temp `core.hooksPath` proxy + shell env; `readGitIgnore/save/appendIgnoreRule/File` (escape `[]!*#?`, CRLF-aware); `var GIT_AUTHOR_IDENT` (128→null).
- NOT supported (don't port): sparse-checkout, `lfs lock(s)`, `gc/prune/notes/bundle/archive`, signing setup (only `--no-gpg-sign` + passthrough error), `filter-repo`, partial/shallow clone.
